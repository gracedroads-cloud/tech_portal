# Prompt Pack

## Core Copilot Prompt Templates

### 1. System Architecture Prompt
Generate a technical architecture document for an enterprise roadside repair and fleet coordination platform. The system must include React frontend, Node.js backend, Socket.IO real-time messaging, GPS tracking, AI-assisted routing, and an after-hours repair network. Keep all workflows aligned to repair-first service and enforce the no-tow policy.

### 2. UI Dashboard Prompt
Create a modern command-center dashboard for a heavy-duty repair and fleet support system. Include dispatch feed, GPS map, technician tracking, service health, and dual-monitor layout. Use blue and orange accent colors and maintain professional enterprise styling.

### 3. Marketing Copy Prompt
Write concise, professional marketing copy for a heavy-duty repair support company. Focus on uptime, fleet continuity, safety, and expert repair coordination. Do not mention tow service or winching.

### 4. Emergency Workflow Prompt
Draft a detailed emergency handling process for commercial roadside service operations. Include hazard checks, risk evaluation, repair-first dispatching, after-hours service pathing, technician assignment, and real-time updates to the command center.

### 5. Documentation Prompt
Generate documentation for a company operating model that includes architecture, policies, brand identity, emergency workflows, and service operations. Keep all content consistent with the repair-only model and no-tow policy.

### 6. GPS Operational Prompt
Design a GPS tracking and routing workflow for trucks, trailers, drivers, and technicians. Include live position updates, ETA calculations, route maintenance, and service status broadcasts.

### 7. Branding Prompt
Write clear brand guidelines for a commercial fleet repair company. Include tone, messaging pillars, visual style, and language that reinforces trust, safety, and uptime.

## Use This Pack
Use these prompts as reusable instruction blocks for Copilot across code generation, documentation, marketing, and operational planning.
